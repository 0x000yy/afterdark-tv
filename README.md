# IPTV Mega / AFTERDARK TV playlist tool

أداة Python تجمع قوائم IPTV العامة المسموح بها قانونيًا، تفكك M3U، تزيل التكرار، وتصدر قوائم M3U8 قابلة للاستخدام في مشغلات التلفاز.

## التشغيل المحلي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python mega-iptv.py
```

بعد اكتمال التحميل اكتب:

```text
one
```

سيُنشأ الملف `ALL_CHANNELS.m3u8` ويبدأ خادمًا محليًا. الرابط المحلي ليس رابطًا عامًا دائمًا؛ يجب أن يبقى الجهاز والخادم قيد التشغيل.

## التحديث المستمر عبر GitHub Actions

يوجد workflow باسم `Update IPTV playlists` يعمل تلقائيًا كل 12 ساعة، ويعمل أيضًا مباشرة عند تعديل ملف `sources.txt` أو الكود. لا تحتاج إلى تشغيل Python أو الأمر `one` على جهازك.

## إضافة رابط IPTV خاص بك

افتح ملف [`sources.txt`](sources.txt) وأضف رابطًا واحدًا في كل سطر:

```text
https://example.com/playlist.m3u8
```

أو أضف اسمًا اختياريًا:

```text
اسم قائمتي | https://example.com/playlist.m3u
```

بعد حفظ التعديل ورفعه إلى GitHub يبدأ التحديث تلقائيًا، ثم تُحدّث القوائم الناتجة. لا تضع روابط خاصة أو كلمات مرور في مستودع عام.

بعد أول تشغيل ناجح، يكون الملف الرئيسي:

```text
https://raw.githubusercontent.com/OWNER/REPOSITORY/main/playlists/all.m3u8
```

استبدل `OWNER/REPOSITORY` باسم المستودع. هذا الرابط يعمل فقط إذا كان المستودع عامًا أو كان المشغل يملك صلاحية قراءة المستودع الخاص.

## القنوات الكبرى

تقوم الأداة بفهرسة أسماء بديلة عربية وإنجليزية لقنوات رياضية وإخبارية وترفيهية كبيرة، وتُصدر قائمة موحدة:

```text
https://raw.githubusercontent.com/0x000yy/afterdark-tv/main/playlists/featured.m3u8
```

وتُصدر قوائم منفصلة داخل `playlists/featured/` مثل `bein-sports.m3u8` و`espn.m3u8` و`mbc.m3u8` و`bbc.m3u8` عند العثور على نتائج لها.

> الاكتشاف لا ينشئ بثًا جديدًا ولا يتجاوز DRM أو الاشتراكات. إذا لم يكن رابط القناة موجودًا في مصدر عام أو في رابط IPTV تملكه وتضيفه إلى `sources.txt` فلن تظهر القناة، خصوصًا القنوات المدفوعة مثل beIN Sports.

## محرك الاكتشاف التلقائي

المحرك لا يحتاج إضافة اسم كل قناة يدويًا. لكل قناة يقرأ:

- اسم القناة واسم المجموعة.
- `tvg-id` وحقول الدولة واللغة.
- رابط البث نفسه عند الحاجة.
- صيغ الكتابة العربية والإنجليزية والاختصارات.

ثم يزيل التكرار ويصنع قوائم ديناميكية في مجلد `playlists/detected/`، مثل:

```text
detected/brand-bein.m3u8
detected/category-sports.m3u8
detected/category-news.m3u8
detected/index.json
```

لذلك إذا ظهر اسم أو علامة جديدة داخل أي مصدر IPTV، يستطيع المحرك تصنيفها تلقائيًا ضمن العلامة أو الفئة المناسبة، وتُحدّث القوائم عبر GitHub Actions.

> GitHub Actions لا يشغّل عملية Python دائمة؛ لكنه يقوم بالنتيجة المطلوبة هنا: يعيد بناء ملف M3U8 تلقائيًا كل 12 ساعة وعند تغيير `sources.txt`. رابط `one` المحلي لم يعد مطلوبًا للاستخدام اليومي.

## ملاحظات قانونية وتقنية

- استخدم القنوات والروابط التي تملك حق استخدامها أو التي ينص مصدرها على إتاحتها العامة.
- لا تتضمن الأداة تجاوز DRM أو الاشتراكات المدفوعة.
- لا تُرفع مفاتيح أو بيانات اشتراك إلى GitHub.
- عدد القنوات ووقت التحديث يعتمدان على المصادر الخارجية وتوفرها.
