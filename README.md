# IPTV Mega / AFTERDARK TV playlist tool

أداة Python تجمع قوائم IPTV العامة المسموح بها قانونيًا، تفكك M3U، تزيل التكرار، وتصدر قوائم M3U8 قابلة للاستخدام في مشغلات التلفاز.

## التشغيل المحلي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python mega-iptv.py
```

بعد اكتمال التحميل اكتب:

```text
one
```

سيُنشأ الملف `ALL_CHANNELS.m3u8` ويبدأ خادمًا محليًا. الرابط المحلي ليس رابطًا عامًا دائمًا؛ يجب أن يبقى الجهاز والخادم قيد التشغيل.

## التحديث المستمر عبر GitHub Actions

يوجد workflow باسم `Update IPTV playlists` يعمل يدويًا أو كل 12 ساعة، ويُحدّث مجلد `playlists/` داخل المستودع.

بعد أول تشغيل ناجح، يكون الملف الرئيسي:

```text
https://raw.githubusercontent.com/OWNER/REPOSITORY/main/playlists/all.m3u8
```

استبدل `OWNER/REPOSITORY` باسم المستودع. هذا الرابط يعمل فقط إذا كان المستودع عامًا أو كان المشغل يملك صلاحية قراءة المستودع الخاص.

> GitHub Actions لا يشغّل خادمًا دائمًا؛ هو يحدّث الملف دوريًا. أما رابط `one` المحلي فيتوقف عند إيقاف الجهاز أو العملية.

## ملاحظات قانونية وتقنية

- استخدم القنوات والروابط التي تملك حق استخدامها أو التي ينص مصدرها على إتاحتها العامة.
- لا تتضمن الأداة تجاوز DRM أو الاشتراكات المدفوعة.
- لا تُرفع مفاتيح أو بيانات اشتراك إلى GitHub.
- عدد القنوات ووقت التحديث يعتمدان على المصادر الخارجية وتوفرها.
